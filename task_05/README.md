# Практическое задание: Docling и поиск похожих фрагментов

В каталоге data/ лежат два PDF: биографии Льва Николаевича и Алексея Николаевича Толстых. Задание состоит из двух последовательных частей.

## Подготовка окружения

Нужен Python 3.10–3.14. Если установлен Python 3.12:

```bash
python3 -m pip install --user uv
uv venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements.txt
```

Если используется другая версия Python, замените 3.12 в команде uv venv
на нужную версию. Для каждого задания активируйте это окружение перед запуском.
При первом запуске task_2.py модель и Docling могут скачать файлы в кэш.

## Задание 1. PDF → очищенный Markdown

В task_1.py реализуйте две функции:

- распознавание PDF с помощью Docling и сохранение Markdown в data/markdown/ с тем же именем файла;
- очистку текста: удаление URL из Markdown-ссылок с сохранением видимой подписи и объединение подряд идущих заголовков уровня ## (например, заголовки «Глава» и «Детство» объедините в «Глава: Детство»).

```bash
python task_1.py
```

Проверьте созданные Markdown-файлы и убедитесь, что оба документа записаны в data/markdown/.

## Задание 2. Похожие фрагменты двух документов

В task_2.py найдите десять самых похожих пар фрагментов из разных документов:

1. Загрузите Markdown-файлы, созданные в задании 1.
2. Разбивайте тексты иерархически с помощью RecursiveCharacterTextSplitter: сначала по заголовкам уровня ##, затем длинные разделы — по абзацам. Начните с размера чанка 1000 и перекрытия 150 символов. Не оставляйте фрагменты короче 128 символов отдельно — присоединяйте их к соседнему.
3. Модель intfloat/multilingual-e5-small загружается готовой частью task_2.py. При первом запуске веса скачаются в кэш. Посчитайте эмбеддинги всех фрагментов через переданную модель: используйте префикс passage:, нормализацию эмбеддингов и progress bar.
4. Для нормализованных векторов посчитайте cosine similarity одним умножением матриц: E @ E.T. Оставьте пары из разных документов и выведите top-10 пар, их score, имя документа и текст фрагмента.
5. Просмотрите результаты и коротко оцените, какие пары действительно похожи по смыслу.

После первого задания запустите:

```bash
python task_2.py
```

## Что сдать

- Реализованные task_1.py и task_2.py.
- Созданные Markdown-файлы из data/markdown/.
- Краткую характеристику top-10 пар из задания 2.
